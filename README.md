Simple Snake — ML Demo

Files
- `index.html` — main page (open in browser)
- `styles.css` — styling
- `game.js` — core game logic and controls
- `ai.js` — simple heuristic AI

Run
1. Open `index.html` in your browser (double-click or serve via static server).
2. Use Arrow keys or WASD to play.
3. Toggle the "AI" checkbox to let the heuristic agent control the snake.

Notes
- This demo uses a deterministic heuristic AI (no training). If you want a Q-learning or TensorFlow.js agent, tell me and I will add it as an optional module.
